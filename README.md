# SQL Music Store Analysis — Basic to Advanced

## Project Overview

This project is based on a digital music store database. It contains SQL queries that solve different business-related questions, starting from basic queries and going up to advanced SQL concepts.

The main focus of the project is to understand customer purchases, invoices, music genres, artists, and country-wise sales using SQL.

## Project Levels

### Set 1 — Easy

Basic SQL questions related to:

* Employees
* Invoices
* Countries
* Customer spending
* Invoice amounts

Concepts used:
`SELECT`, `WHERE`, `GROUP BY`, `ORDER BY`, `SUM()`, `COUNT()`, `MAX()`, `LIMIT`, and basic `JOIN`.

### Set 2 — Moderate

Questions related to:

* Customers listening to Rock music
* Top Rock artists
* Tracks longer than the average track length

Concepts used:
`JOIN`, `DISTINCT`, subqueries, `AVG()`, `COUNT()`, filtering, and sorting.

### Set 3 — Advanced

More complex questions related to:

* Best-selling artists
* Most popular genre in each country
* Highest-spending customer in each country

Concepts used:
CTEs, recursive CTEs, window functions, `ROW_NUMBER()`, `PARTITION BY`, subqueries, and multiple-table joins.

## Database Tables

* `employee` — Employee details
* `customer` — Customer information
* `invoice` — Invoice and billing details
* `invoice_line` — Products purchased in each invoice
* `track` — Song/track information
* `album` — Album details
* `artist` — Artist information
* `genre` — Music genre details

## SQL Concepts Used

* SELECT and WHERE
* GROUP BY and HAVING
* ORDER BY and LIMIT
* DISTINCT
* Aggregate functions
* INNER JOIN
* Subqueries
* CTEs
* Recursive CTEs
* Window functions
* ROW_NUMBER()
* PARTITION BY
